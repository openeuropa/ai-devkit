# Writing conventions

ASCII only in generated files: no Unicode arrows, long dashes, curly quotes or
box drawing. Comment every file, function, type and non-obvious block; keep
comments compact. Wrap Markdown at 80 columns. Match the naming already used
in the file you edit.

Git: commit only when asked. Commit messages are one line, no body, no
trailers. Branch names follow the ticket id (`OEL-1234`, `EWPP-1234`).
